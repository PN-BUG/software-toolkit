# 蒲公英降落台（Android）

“蒲公英降落台”是“局域网文件共享”的可选独立伴侣工具。没有安装它时，原来的扫码、上传、下载和聊天功能仍可单独使用。

安装并启动蒲公英降落台后，它会以前台服务在局域网内广播设备，并监听连接请求。即使浏览器没有打开，也会显示高优先级系统通知：

- 点击“同意并打开”会回复发起方，并自动在浏览器打开共享网址。
- 点击“拒绝”会把拒绝结果回复给发起方。
- 蒲公英降落台仅监听同一局域网，不使用云端中转。

## 安装

双击 `install-bridge.bat`。如果电脑已安装 ADB 且手机已开启 USB 调试，会自动安装；否则会定位到 `DandelionLanding.apk`，可将其发送到手机后手动安装。

首次启动请允许通知，并在系统电池设置中允许该应用后台运行。蒲公英降落台运行时会保留一条低优先级常驻通知，这是安卓保证后台监听稳定性的要求。

## 限制

- 手机和发起设备必须位于允许互相访问的同一局域网；启用了“客户端隔离”的 Wi-Fi 无法使用。
- 如果用户在系统设置中“强行停止”应用，安卓会停止所有后台接收，必须重新打开一次蒲公英降落台。
- 这是安卓伴侣端；iPhone 的后台通知需要 APNs 云推送，纯局域网无法等价实现。

## 从源码构建

源码位于 `android-src`，不依赖 Gradle 或第三方库。Windows 上安装 JDK 17 与 Android SDK 35 后运行：

```powershell
.\build-android.ps1
```

构建脚本使用 Android SDK 自带的 `aapt2`、`d8`、`zipalign` 和 `apksigner`。签名密钥默认生成到仓库根目录 `.build-keys`，不会打入发布包。
